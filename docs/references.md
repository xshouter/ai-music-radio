## 被复刻的原型

**Claudio x mmguo FM** —— 一个私人 AI 电台，作者 mmguo。

- 站点：<https://mmguo.dev/claudio-fm/>
- 它长什么样：`LISTENER 1` 与 `ON AIR 24/7` 状态、正在播放的封面、逐行高亮的歌词、
  英文口播文字流、UPnP 输出设备选择。
- 它的行为：DJ 自己排当天的节目表、自己挑歌、自己写一段英文口播，把歌和话串成一条不断的流。

**本仓库与原作者无关**，不使用其任何代码或素材。我们复刻的是「行为的形状」——信息架构与交互，
代码从零写。原型的截图与录屏只作本地对照，**不进仓库**（`.gitignore` 已忽略 `docs/reference/`）。

## 从原型读出来的 6 条契约线

`POST /api/chat`、`GET /api/now`、`GET /api/next`、`GET /api/taste`、`GET /api/plan/today`、`WS /stream`

原版的输出协议（由行为观察得到）：`{ say, play[], reason, segue }`。

## 我们主动选择的不同

| 维度 | 原型 | 本项目 | 为什么 |
|---|---|---|---|
| 大脑 | 未公开 | 自建 tool loop，**provider 无关**（任何 OpenAI/Anthropic 兼容的 key 都能用） | 作品集要展示 agent 设计能力，而不是"调了一个 SDK" |
| 音乐源 | 未公开 | 网易云为主 + 本地兜底，做成可替换的降级链 | 版权处于灰色地带，必须隔离在一个端口后面 |
| 存储 | 未公开 | SQLite（better-sqlite3） | 单机单用户，够用、可离线、无需部署 |
| 口播语言 | 英文 | 英文（同） | 原型听起来就是英文电台，口播是它的一半质感 |
| 交付形态 | 托管站点 | 本地 exe，**用户自带 key** | 只服务作者一人；别人下载 exe 后填自己的 API |
| 输出设备 | UI 里可选 UPnP 播放设备 | **不复刻**，声音只从本机出 | v1 只服务作者一台 PC，没有第二个真实播放目标（ADR-0007） |

## 版权与使用边界

- 音乐播放属于**个人自用**场景。所有取流逻辑集中在 `MusicSource` 端口后，
  换一个合法音源只需新增一个实现，不改动编排层。
- 仓库里不附带任何音频、歌词或封面素材；缓存目录 `cache/` 与运行数据 `data/` 均不提交。
