## 22 · 语音引擎：Fish Audio 换成离线 Piper（ADR-0022）、只发便携 exe（ADR-0023）、应用图标

### 遇到的困难

1. **Fish Audio 到不了。** `fish.audio` 与 `api.fish.audio` 的 DNS 被污染成假 IP，HEAD 一律超时 —— 官网打不开，key 拿不到；**即使手里有 key，API 主机本身也不通**。这条路由彻底断了。
2. **官方 GitHub 也没有替代品。** 把 fishaudio 的 28 个仓库过了一遍：`fish-speech` 要 GPU + 数 GB 权重；`s1-mini`（0.5B）是 **gated** 仓库且许可是 **CC-BY-NC-SA-4.0（非商用）**；`docs` 里的自托管是企业 Kubernetes / Docker，最省的 all-in-one 也要 **H100 级 80GB 卡**，还得先有企业协议、再登录官网建 deploy token；其余是 SDK / 插件 / AGPL / CUDA 算子。**没有一个能塞进便携 exe。**
3. **百炼这把 key 不做语音。** `/models` 通，但 `/audio/speech` 400、`tts-1` 404、`chat/completions + modalities:['text','audio']` 500 —— 这个网关只放通 chat 路由。
4. **Edge TTS 放弃。** 上游现在要带一个**刻意混淆的 DRM token**（`drm.py` 里几十行常数）；实测裸 WebSocket → 403。把这种东西当作品集的依赖是负资产。
5. **本机 SAPI 只有 1990 年代的嗓子**（Zira / David / Huihui），配不上这个界面。
6. **`piper.exe` 不能在中文路径下跑。** espeak-ng 用 `fopen` 读 `espeak-ng-data/phontab`，非 ASCII 路径下直接崩，而且**静默产出 0 字节**（第一遍排查只看到空音频，一句报错都没有）。
7. **GitHub Release / HF 的下载被 hosts 劫持。** `github.com` / `objects.githubusercontent.com` / `api.github.com` / `huggingface.co` 全指向 `127.0.0.1`；`gh release download` 会挂死（0 字节、进程不退）。绕法：`gh-proxy.com`（实测 6.5 MB/s）与 `hf-mirror.com`。
8. **工具箱塌了一半。** `apply_patch` 不可用、`FileSystem` MCP 被策略拦 —— 改文件退回 PowerShell here-string + Node 脚本（**必须断言命中次数**）。

### 怎么改的 / 为什么

- **语音换 Piper**（MIT、离线、纯 CPU）：`core/providers/tts-piper.ts` + `tools/fetch-voice.mjs`（首次拉运行时与音色到 `vendor/piper/`）。理由逐条写在 ADR-0022 里，就是上面 1–5 的实测。
- **抽象层只动一处：加 `format`。** 容器格式是**引擎级属性** —— 缓存后缀、`Content-Type`、时长解析都该由它决定。改完这一处，以后再换任何引擎都不用碰缓存与路由。因为它动了契约，所以补了 ADR，而不是顺手改掉。
- **非 ASCII 路径**：`main/tts-runtime.ts` 的 `resolveTtsDir` 在安装路径非 ASCII 时，把运行时整份拷到第一个可写的 ASCII 落点。写成**不 import electron 的纯函数**，冒烟脚本共用同一套规则 —— 这是 ADR-0021「唯一组装点」的红利。
- **只发 portable**（ADR-0023）：双击即用、无管理员权限、无注册表、无残留；用户数据本来就在 `%APPDATA%\EdgeRunner`，换 exe 不丢数据。代价（没有快捷方式 / 卸载器、冷启动要解包）写进了 ADR。
- **图标**：`tools/make-icon.mjs` 零依赖生成 PNG + 7 尺寸 ICO（16/24/32/48/64/128/256）。图形与界面同源：Doto 风格的点阵拼成一个向右的播放三角。
- **界面：通栏 + 氛围感**（对着参考逐像素量的）：去掉「窗口里套四张内嵌描边小卡片」，改成通栏分区、靠背景深浅区分；文字墨量从 210 压到参考的 130 附近；VOL 换自绘滑轨（52px 轨 + 11px 白圆点）；`.cut` 分隔元素整条删除。

### 验证证据

- `node --experimental-strip-types tools/smoke-tts.mjs --provider=piper` → `✓ audioUrl: /tts/bf623b5f….wav · 字节 273684 · 词数 14 · 总长 6205ms`，词表与真实时长对齐。
- WAV 头核验：`RIFF/WAVE/fmt/data`、1ch、22050Hz、16bit，273640 ÷ 44100 = 6.205s —— 与 `wavDurationMs()` 同源同口径。
- 图标自检：7 个尺寸的墨迹都在画布正中（偏移 0.0）且不贴边。改之前 **16px 完全检测不到墨迹**（点被降采样抹平），而自检又把 `x1 === -1` 算成「居中」—— **假通过**；两处一起修掉（空墨迹直接判失败）。
- 四件套：`boundaries`（renderer 17 / core 20 / main 4 / shared 3）、`typecheck`、`test` **74/74**、`build` 全过。

### 留给自己的一条

一个"只是换个 TTS"的改动，代价是**先证明所有免费 / 自托管的路线都不通**：官方 GitHub 28 个仓库、三个云网关路由、一个要 DRM token 的上游。这里的判断力不在"选哪个模型"，而在**"哪条路在约束下根本走不通"** —— 并且要把"走不通"的证据留下来。
