# 需求：池子优先（排表那一轮的两段式 + 提示词里的 flavour）

> 铁律 2 的产出。这份文件回答「这一轮被要求做成什么」，**不回答**「怎么实现」（那在 ADR-0031）。
> 来源：PR #57 的真数据验证 —— `tools/smoke-plan.mjs --live` 实测「日表 9 首里只有 1 首来自日推」。

## 摸底：缝到底在哪

模型**拿到了**那 30 首（工具结果里有标题和歌手），第一步也确实调了 `daily_recommend` ——
但它没法确认哪首对得上 `acoustic + jazz`，于是每一格都搜一遍保命。一轮排表实测：
音乐源请求 12 次（日推 1 + 搜索 11）、工具调用 13 次、36 秒，最后 9 首里 1 首来自日推。

所以这不是「提示词忘了写」（`PLAN_PERSONA` 与 user 段两条都写了），而是两件事叠在一起：
**「池子里够不够」在模型眼里不可判定**，而**「每格 3 首」是个硬配额**。

## 行为（冻结）

1. **两段式**：第一轮的工具集**没有** `search_tracks`
   （`POOL_TOOLS = daily_recommend + recent_plays + emit_plan`）—— 模型只能用池子填三格；
   代码数出「不满 3 首」的格，才对**那几格**发第二轮
   （`SEARCH_TOOLS = search_tracks + emit_plan`，槽位**重新编号**）。**最多两轮，不递归。**
2. **池子优先是默认，搜索是例外**：第一轮不给搜索；第二轮每格最多 1 次。
3. **`genres` 在提示词里降级成 flavour**：三格呈现为「氛围提示，不是过滤器」；
   `BLOCKS.genres` 仍只给 `searchBlock` 兜底用（数据一句不动）。
4. **「少给」是合法结果**：一格 2 首、1 首、空着都收，不因为少给而驳回。
5. **清单瘦身**：`daily_recommend` 与 `search_tracks` 给**模型**的那份只留 `id / title / artist`；
   `registry` 里仍存完整 `Track`（播放要用）。理由里有一条是对称：不让「搜来的」看起来比「池子里的」更有料。
6. **第二轮失败只退一格**：第二轮整轮失败 → 保留第一轮的结果（那几格就是少给），
   不许把整份日表搞坏 —— 与 ADR-0030 的「缺哪格补哪格」同一条。
7. **任何一步失败都不许把电台停掉**（ADR-0024 / ADR-0030）不变。
8. **`boot()` 的顺序不变**（Q5）。**外部形状不变**：`PlanCurator` / `DayPlan` / `PlanBlock` / UI 都不动。

## 与 `docs/requirements/daily-plan.md`（#56）的差异

- 那里冻结的 `PLAN_TOOLS`（一份四件）**拆成两套**：`POOL_TOOLS` / `SEARCH_TOOLS`。
  `TOOLS`（播歌那一轮）仍然一个字都不动。
- 那里 Q5 的答复「能从日推，也允许自己搜」**仍然成立**，只是把「先掏池子」从措辞变成了编排：
  搜索不是被禁止，是被**安排在后面**。

## 不做

- 不动 `PlanBlock` / `DayPlan` 契约，不新增「这格只有 2 首」的标记字段。
- 不动 `boot()` 里排表与开口的先后（那是另一条决策）。
- 不动 `netease.recommend` 的两级退让（ADR-0016）。
- **UI 无改动**：日表本来就是 `plan` 事件 + `/api/plan/today`（铁律 3 在这一轮没有前端面）。

## 验收

- 单测 `tests/core/brain.test.mjs`：第一轮请求里**没有** `search_tracks`；三格填满 → **只发一轮**；
  某格少给 → 第二轮**只带那一格**；第二轮失败 → 第一轮结果保留；第二轮补上的 id 进对格。
- 单测 `tests/core/plan.test.mjs`：一格只给 2 首也照收（少给不算坏）。
- 单测 `tests/core/prompt.test.mjs`（新）：三格在提示词里是 flavour 而不是过滤器；
  `search_tracks` 不出现在第一轮的 user 段。
- 真数据 `tools/smoke-plan.mjs --live` **连跑 3 次**：音乐源请求、用时、9 首里来自日推的条数，
  三次全记进 ADR-0031 与 journal（门槛：3 次里 ≥2 次达标）。
